# Changelog

All notable changes to Zenthrix Benchmarks are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-18

### Added

- `zenthrix-benchmarks` Python package and `zbench` command-line utility.
- Validation for benchmark metrics, run metadata, and hardware/model context.
- Deterministic Markdown comparison reports with metric-aware winners.
- Example versioned benchmark result envelope.
- uv development workflow and GitHub Actions validation across Python 3.10–3.13.
- Package build artifacts for the first public release.
